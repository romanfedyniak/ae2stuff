# AE2 Stuff Unofficial Deconstructed

Blocks and tools for [AE2 Unofficial Deconstructed](https://github.com/romanfedyniak/AE2UD) on Minecraft 1.12.2.

This is a rewrite in Java of [AE2 Stuff](https://github.com/bdew-minecraft/ae2stuff) by bdew, by way of the
[AE2 Unofficial Extended Life fork](https://github.com/AE2-UEL/ae2stuff). It is written against AE2UD and does not
run with any other AE2 build.

See [CHANGES.md](CHANGES.md) for what it adds and how it differs from the mod it continues.

## Requirements

* Minecraft 1.12.2 with Minecraft Forge.
* AE2 Unofficial Deconstructed 1.6.0 or newer, with what it requires.

## Building

Gradle runs on Java 25: `./gradlew build`. AE2UD is fetched from [JitPack](https://jitpack.io), so nothing has to be
built first.
